# CodeAlpha Flashcard Quiz App

A beginner-friendly flashcard study app built with HTML, CSS, and vanilla JavaScript for the CodeAlpha App Development internship.

## Features

- View a question and reveal its answer.
- Navigate using Previous and Next.
- Add, edit, and delete flashcards.
- Saves cards in browser local storage.
- Responsive layout for desktop and mobile.
- Starts with five sample web-development cards.

## Run locally

1. Download or clone this project.
2. Open `index.html` in a modern browser.
3. Add your own cards and refresh the page to confirm they persist.

No build tools or dependencies are required. The Google Fonts import is optional; the app uses fallback fonts if you are offline.

## Project files

- `index.html` — page structure
- `style.css` — layout and visual design
- `script.js` — flashcard behavior and local storage

## Manual testing checklist

- [ ] Show answer switches the displayed question to the answer.
- [ ] Show question returns to the question.
- [ ] Previous and Next move through cards and disable at the ends.
- [ ] Add a card and confirm it appears in the list and study mode.
- [ ] Edit a card and confirm its question and answer update.
- [ ] Delete a card and confirm it disappears after confirmation.
- [ ] Refresh the browser and confirm cards remain saved.
- [ ] Try an empty form and confirm the browser asks for required fields.
- [ ] Test at a narrow mobile width.
